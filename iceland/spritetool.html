▶ 01 轉換頁

1

在 Aseprite 匯出

File → Export Sprite Sheet
Layout → Sheet type: Horizontal（全部 frame 橫排）
存成 PNG，背景建議設為透明
建議畫布尺寸：16 × 28 px / 格

2

設定參數

Frame Width / Height：單格像素大小（通常 16×28）
Frame Count：幾個動畫格（通常 4）
BG Threshold：透明 PNG 設 0，黑底不透明設 60
變數名稱：之後在程式碼裡的名字，建議填角色識別名

3

轉換 → 存入角色庫

按 ▶ CONVERT 看到預覽動畫沒問題後
按 💾 存入角色庫 → 輸入角色名稱 → 確認
角色就會出現在「角色庫」頁

透明色判斷：透明 PNG 選「Alpha 通道」；如果圖片有黑色邊框或陰影被誤判為背景，改用「兩者都用」並調高 Threshold。

▶ 02 角色庫頁

★

管理所有角色

這裡儲存了所有旅程畫過的角色，動畫 8fps 預覽
IN USE 標籤表示此角色正被某旅程成員使用
滑鼠移上去出現 ✕ 可以刪除角色（已使用的會自動解除綁定）

★

備份與還原

匯出 JSON 備份：把所有角色存成 .json 檔案到電腦
匯入 JSON 角色庫：從備份還原，重複的角色會自動跳過
建議每次畫了新角色就匯出一次備份

▶ 03 旅程綁定頁

1

新增成員

輸入成員名稱（要和 Google Sheet 欄位名稱一致）
例如 Sheet 有「猴負擔」欄位，成員名稱就填 猴

2

選角綁定

點成員左側的預覽框或「選角」按鈕 → 跳出角色庫選角
選角後頭像會顯示，邊框變綠色代表綁定成功

3

生成程式碼

所有成員都綁定後按 ⚡ 生成程式碼
會輸出兩段：sprites.js 的 frames 變數 + config.js 的 members 設定
複製後貼到旅程資料夾對應的檔案裡

4

貼入網站

sprites.js：把生成的 const XXX_FRAMES = [...] 貼進去，
並確認 window.SPRITES 裡有包含新的 key
config.js：把 members: [...] 整段替換

換新旅程的完整流程：
複製舊旅程資料夾 → 清空 sprites.js 的角色 frames → 用這個工具生成新角色的程式碼貼進去 → 更新 config.js 的 members、tripName、apiBase、dates → 更新 sw.js 的 CACHE_NAME 和路徑 → 部署

▶ 04 場景 ID 說明

!

每個成員在 HTML 有三個 id

生成的 config.js 裡每個成員有三個 id 欄位：
sceneId：會動的 SVG 動畫元素（sprites.js 動畫迴圈用）
charId：場景裡角色容器，控制左右位置（scene.js 用）
bubbleId：對話泡泡元素（scene.js 用）
這三個 id 要和 index.html 裡的 HTML 元素 id 對應，不要隨便改

新旅程加新角色時，如果 index.html 裡的 id 和舊旅程一樣（例如都用 svgHana），只需要替換 sprites.js 的 frames 內容就好，不用改 config.js 的 id 欄位。
